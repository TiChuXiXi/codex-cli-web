# RCC 工作环境只读查询验收记录

日期为 2026-11-20，基线为 feature/router 的 b83e6e6 和该工作树已有的项目列表补丁。

## 实现边界

明确的列表查询沿用本地回复。任务模式的自然语言使用同一个 Router 主线程的结构化意图回合，服务端拒绝该回合的工具请求。普通业务可能比原路径多一次 Router 回合。服务端按核验过的目录、PSM、任务及 command 记录生成查询回复。查询失败会提示资料不足或请用户澄清。

目录中独立可发现的未授权项目仅展示名称和待授权标记。仅存在于历史索引的未授权项目不参与列表、主题和计数。识别到混合请求时分别记录查询回复和业务投递。泛指全部项目的业务工作要求指定先处理的目标，具名多会话续接继续使用现有 RCC。常见规模一次返回，超过渠道长度预算或每页 50 项时可在原查询中注明页码。再次查询时按当前授权重算结果。

| 手机操作 | 对照证据 |
|---|---|
